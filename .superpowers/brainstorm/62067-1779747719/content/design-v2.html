CI Workflow Design (v2)

Updated with Biome for ultra-fast linting and formatting.

.github/workflows/ci.yml
Triggers
  • push to main
  • pull_request to main
  • workflow_dispatch (Manual)
Job: quality-and-test
  • OS: ubuntu-latest
  • Node: lts/*
  • Tools: npm, biome
Execution Steps
  1. npm ci — Install dependencies
  2. npx @biomejs/biome ci . — Lint and check formatting (Fast!)
  3. npx tsc --noEmit — Static type checking
  4. npm test — Run vitest suite
  5. npm run build — Verify production build

Final Design Approval

This setup ensures that code is formatted correctly, has no lint errors, passes type checks, and all tests are green before it reaches main.
