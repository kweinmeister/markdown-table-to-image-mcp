Proposed CI Steps

A typical TypeScript CI pipeline ensures code quality and build integrity at every step.

Workflow: CI
Job: build-and-test
  • Checkout: Pull the latest code.
  • Setup Node.js: Use the project's required version (and cache node_modules).
  • Install: npm clean-install
  • Type Check: tsc --noEmit to catch TypeScript errors.
  • Test: npm test (vitest) to run unit and integration tests.
  • Build: npm run build (tsup) to verify the production bundle.
