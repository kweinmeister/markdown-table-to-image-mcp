Refined CI Workflow Design (v3)

Applying performance optimizations and best practices.

.github/workflows/ci.yml
Optimized Triggers
  • pull_request to main — Catch issues before merging.
  • workflow_dispatch — Manual override for debugging.
  • (Push to main removed to avoid double-runs on merge)
Job: quality-and-test
  • OS: ubuntu-latest
  • Node: 22 (Pinned for stability)
  • Caching: actions/setup-node with cache: 'npm'
Scripts (package.json)
  • "lint": "biome ci ."
  • "typecheck": "tsc --noEmit"
Execution Steps
  1. npm ci — Fast install via cache
  2. npm run lint — Fast fail on style/lint
  3. npm run typecheck — Verify type safety
  4. npm test — Run vitest suite
  5. npm run build — Verify production build

Design Improvements Applied

  • Speed: npm caching saves minutes on every run.
  • Stability: Pinned Node 22 prevents unexpected breakages.
  • Efficiency: Removed redundant push-to-main trigger.
  • Consistency: Using npm scripts ensures CI matches local dev commands.
